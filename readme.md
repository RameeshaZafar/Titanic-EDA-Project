\# Titanic Dataset - Exploratory Data Analysis (EDA)



\## Project Overview



This project performs a complete Exploratory Data Analysis (EDA) and data cleaning process on the Titanic dataset. The objective is to understand the dataset, identify patterns, handle missing values, detect outliers, visualize relationships, and prepare the data for machine learning.



\---



\## Dataset



Source:

https://www.kaggle.com/competitions/titanic



The dataset contains passenger information including:



\- Passenger ID

\- Passenger Class

\- Name

\- Gender

\- Age

\- Family Information

\- Ticket Details

\- Fare

\- Cabin

\- Embarkation Port

\- Survival Status

\## Data Cleaning Performed



\- Missing Age values filled using Median

\- Missing Embarked values filled using Mode

\- Cabin missing values handled appropriately

\- Duplicate records checked

\- Unnecessary columns removed for machine learning preparation (where applicable)

\## Key Findings



\- Female passengers had a higher survival rate than males.

\- First-class passengers were more likely to survive.

\- Passenger class strongly influenced survival.

\- Fare showed a positive relationship with survival.

\- Missing values were successfully handled.
